# tests 文件夹说明书

## 核心功能

承载本地机会匹配 CLI 的回归测试，验证匹配逻辑、飞书快照导入、每日邮箱入库、候选人工作流、白名单推送、简历更新和招聘方合作草稿闭环。

## 输入

内存 SQLite 数据库、测试飞书快照、测试候选人、测试岗位、测试招聘方联系人、模拟 lark-cli 输出、模拟附件下载器和模拟飞书群机器人发送器。

## 输出

`unittest` 测试结果，用于证明本地核心闭环可运行。

## 定位

这是 `opportunity_matcher/` 的自动化测试目录，不保存生产数据和真实简历附件。

## 依赖

依赖 Python 标准库 `unittest` 和 `sqlite3`，以及 `opportunity_matcher` 源码包。招聘方合作和邮箱入库测试必须 mock 外部 `lark-cli`、附件下载和 webhook，不访问真实飞书邮箱或真实群机器人。

## 维护规则

- 每次新增、删除、移动文件或调整职责后，必须检查并更新本 README。
- 文件夹职责影响项目基础文档时，必须同步更新 `docs/CLI.md`。
