# tests 文件夹说明书

## 核心功能

承载本地机会匹配 CLI 的回归测试，验证匹配逻辑、飞书快照导入、工作流、白名单推送和简历更新。

## 输入

内存 SQLite 数据库、测试飞书快照、测试候选人、测试岗位和测试招聘方联系人。

## 输出

`unittest` 测试结果，用于证明本地核心闭环可运行。

## 定位

这是 `opportunity_matcher/` 的自动化测试目录，不保存生产数据和真实简历附件。

## 依赖

依赖 Python 标准库 `unittest` 和 `sqlite3`，以及 `opportunity_matcher` 源码包。

## 维护规则

- 每次新增、删除、移动文件或调整职责后，必须检查并更新本 README。
- 文件夹职责影响项目基础文档时，必须同步更新 `docs/basic/`。
